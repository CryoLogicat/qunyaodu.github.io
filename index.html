AI-ASSISTED EXPERIMENTS

HIT Timetable Android / 哈工大课程表 App

A timetable app for HIT students · Android / Kotlin · AI-assisted coding

这是一个从个人查课表需求出发的 Android 应用，面向哈尔滨工业大学本部教务系统导出的网格课表格式。 它希望让查看课程、切换周次、记录考试提醒这类日常动作更方便。

项目主要通过 AI 编程工具辅助实现。我在过程中负责提出需求、拆分功能、反复沟通、测试使用和反馈问题。 这也是我第一次比较完整地体验从需求描述到功能迭代，再到可用工具的过程。

View on GitHub → Feedback / Issues

What it does

  • 导入 HIT 本部 `.xls` 网格课表
  • 按当前周显示课程并支持周次切换
  • 支持考试提醒与桌面小组件
